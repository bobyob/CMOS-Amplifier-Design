# CMOS-Amplifier-Design

This project is a three-stage CMOS amplifier designed for the ELE404 Electronic Circuits 1 course. The architecture features two cascaded Common-Source gain stages with active PMOS loads and a Common-Drain output buffer. Designed and simulated using KiCAD, the circuit was engineered to meet strict performance metrics, including a voltage gain of 60 dB or greater, power consumption under 1mW, an input resistance of at least 100kΩ, and a minimum bandwidth of 500kHz.
